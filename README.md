# ระบบลงทะเบียนเข้าใช้งานอาคารและกิจกรรมกีฬา (Building & Sports Club Access System)
### อาคารอเนกประสงค์ ต.0025 การไฟฟ้าฝ่ายผลิตแห่งประเทศไทย (กฟผ.) สำนักงานไทรน้อย

---

## 🌟 ภาพรวมการปรับปรุงระบบ (Overview of Changes)

ระบบได้รับการยกระดับจากเดิม (บันทึกสนามบาสเก็ตบอลเดี่ยว) เป็น **"ระบบลงทะเบียนเข้าใช้งานอาคารในภาพรวม"** ที่รองรับกิจกรรมของทุกชมรมกีฬาและพื้นที่อาคาร พร้อมระบบฐานข้อมูลรูปแบบใหม่ รองรับการดูประวัติ การวิเคราะห์สถิติ และการ Export ข้อมูลออกเป็นไฟล์ Excel / CSV ได้ทันที

---

## 🚀 คุณสมบัติเด่น (Key Features)

### 1. แยกเมนูตามกิจกรรมแต่ละชมรม (Club & Facility Segmentation)
- 🏀 **ชมรมบาสเก็ตบอล (Basketball Club):** คอร์ตบาสเก็ตบอลในร่ม (ธีมสีส้มสดใส)
- ⛳ **ชมรมกอล์ฟ (Golf Club):** สนามไดรฟ์กอล์ฟ 8 ช่อง & กรีนพัตต์ (ธีมสีเขียวมรกต)
- 🎯 **ชมรมยิงธนู (Archery Club):** ลู่ยิงธนูมาตรฐาน 10ม. และ 18ม. (ธีมสีแดงทับทิม)
- 🏸 **ชมรมแบดมินตัน (Badminton Club):** คอร์ตแบดมินตัน 1-3 พื้นยางมาตรฐาน (ธีมสีฟ้าสด)
- 🦺 **อบรมหลักสูตรการทำงานบนที่สูง (Working at Heights Training):** ศูนย์ฝึกอบรมการทำงานบนที่สูงและเสาจำลอง อาคาร ต.0025 (ธีมสีเหลืองทองความปลอดภัย)
- มีแถบ **Quick Club Switcher** และหน้ารวมข้อมูลชมรม (Directory) สามารถสลับชมรมได้ด้วยคลิกเดียว

### 2. ระบบฐานข้อมูลรูปแบบใหม่ (New Database Engine)
- **Local Database (IndexedDB v2):**
  - ชื่อฐานข้อมูล: `EGAT_BuildingAccessDB`
  - ตาราง: `access_logs`
  - จัดเก็บข้อมูลถาวรใน Browser (ความจุสูง ไม่หายเมื่อปิดเครื่อง ใช้งานแบบ Offline ได้สมบูรณ์)
  - เก็บข้อมูลครบถ้วน: `id`, `userName`, `department`, `empId`, `clubId`, `clubName`, `zone`, `checkInTime`, `checkOutTime`, `durationMinutes`, `status`, `note`, `createdAt`
- **ระบบ Cloud Database เชื่อมโยงทุกเครื่องแบบ Real-time (2-Way Cloud Sync):**
  - ใช้ **Google Sheets (ผ่าน Apps Script Web App)** เป็นฐานข้อมูลออนไลน์กลางฟรี
  - เมื่อผู้ใช้สแกน QR Code ลงทะเบียนผ่านมือถือเครื่องใดก็ตาม ข้อมูลจะถูกบันทึกส่งไปยัง Google Sheets กลางทันที
  - เมื่อเปิดเว็บจากคอมพิวเตอร์หรืออุปกรณ์อื่น ระบบจะดึงข้อมูลทั้งหมดจาก Google Sheets มาแสดงผลในตารางประวัติทันที ทำให้ทุกเครื่องเห็นประวัติและสถิติชุดเดียวกัน
  - มีไฟล์ `google_sheets_apps_script.js` สำหรับติดตั้งบน Google Sheets ได้ทันทีใน 2 นาที
  - มีไฟล์ `database_schema.sql` เผื่อต้องการติดตั้งบน PostgreSQL / Supabase / MySQL ขององค์กร

### 3. ประวัติการใช้งานและระบบ Export ข้อมูล (History & Export)
- **ค้นหาและกรองข้อมูลอย่างละเอียด (Live Filter):**
  - กรองตามชมรม (บาสเก็ตบอล, กอล์ฟ, ยิงธนู, ฯลฯ)
  - กรองตามสถานะ (🟢 กำลังใช้งานอยู่ในอาคาร / ⚪ เช็คเอาต์แล้ว)
  - กรองตามช่วงเวลา (วันนี้, 7 วันล่าสุด, เดือนนี้, ทั้งหมด)
  - ค้นหาด้วยชื่อ สังกัด หรือหมายเหตุ
- **การส่งออกข้อมูล (Export Formats):**
  - 📊 **Export Excel (.xlsx):** สร้างไฟล์ Spreadsheet แท้ ผ่าน SheetJS พร้อมจัดความกว้างคอลัมน์และหัวตารางภาษาไทย
  - 📄 **Export CSV:** มี UTF-8 BOM (`\uFEFF`) เปิดใน Microsoft Excel บน Windows ได้ทันทีโดยภาษาไทยไม่เป็นภาษาต่างดาว
  - 🖨️ **Print Report:** มีสไตล์สำหรับพิมพ์เอกสารหรือบันทึกเป็น PDF สรุปส่งผู้บริหาร
  - 💾 **Backup JSON / Restore:** สำรองและกู้คืนฐานข้อมูลได้

### 4. ออกแบบหน้าตาให้เหมาะสมทั้ง มือถือ และ คอมพิวเตอร์ (Responsive UI/UX)
- **บนมือถือ (Mobile / Tablet):**
  - แถบนำทางด้านล่าง (Bottom Navigation Bar) ใช้งานง่ายด้วยนิ้วโป้ง
  - ปุ่มลงทะเบียนขนาดใหญ่ กดง่าย พร้อมระบบสั่นตอบรับ (Haptic Feedback)
  - นาฬิกาดิจิทัลขนาดใหญ่ แสดงวันเวลาแบบเรียลไทม์
  - การ์ดเลือกชมรมเลื่อนแนวนอน (Horizontal Touch Carousel)
- **บนคอมพิวเตอร์ (Desktop Web / Kiosk):**
  - Responsive Grid 2 คอลัมน์ (แผงลงทะเบียนซ้าย + สถานะสนามและผู้ใช้งานขวา)
  - ป้ายแสดงยอดคนในอาคารแบบ Live Pulse Indicator
  - ตารางข้อมูลขนาดเต็มพร้อมการจัดเรียงและจัดการข้อมูล
  - หน้าแดชบอร์ดสถิติภาพรวม (Analytics KPI) แสดงกราฟสัดส่วนการใช้งานแต่ละชมรมและแผนก

## 💡 วิธีการใช้งาน

1. **เปิดใช้งานหน้าเว็บ:**
   - เปิดไฟล์ `index.html` ผ่าน Browser หรือเข้าผ่าน URL ที่ Deploy ไว้บน Vercel
2. **ตั้งค่าผู้ใช้งาน (ครั้งแรก):**
   - กรอกชื่อ-นามสกุล, เลือกสังกัด/ฝ่าย (เช่น ส่วนกลาง ชธธ., อบค., อบฟ., ฯลฯ)
3. **ลงทะเบียนเข้าใช้งาน (Check-in):**
   - แตะเลือกชมรมที่ต้องการ (บาสเก็ตบอล, กอล์ฟ, ยิงธนู, ฯลฯ)
   - กดปุ่ม **"🟢 ลงทะเบียนเข้าใช้งาน"**
4. **ลงทะเบียนออกจากอาคาร (Check-out):**
   - เมื่อใช้งานเสร็จ ให้กดปุ่ม **"🚪 ลงทะเบียนออกจากอาคาร"** ระบบจะคำนวณระยะเวลา (นาที) และบันทึกลงฐานข้อมูลให้อัตโนมัติ
5. **ดูประวัติและ Export:**
   - ไปที่แท็บ **"ประวัติและการบันทึก"**
   - กดปุ่ม **"Export Excel (.xlsx)"** หรือ **"Export CSV"** เพื่อดาวน์โหลดรายงาน
